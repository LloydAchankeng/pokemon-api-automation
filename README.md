# Pokémon API Automation Tool

A modular Python automation project that interacts with the PokeAPI to fetch real Pokémon data, including stats, abilities, and moves.

## Features
- Real API requests using `requests`
- Error handling with `try/except`
- Clean logging with `logging`
- Modular architecture (`pokemon_api.py`, `logger.py`, `main.py`)
- JSON parsing for stats, abilities, and moves
- Professional project structure suitable for job applications
